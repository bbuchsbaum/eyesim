# Declare no geometric registration for GazeWeave

Declare no geometric registration for GazeWeave

## Usage

``` r
gaze_warp_none()
```

## Value

A \`gaze_warp_spec\` object.

## Examples

``` r
gaze_warp_none()
#> $type
#> [1] "none"
#> 
#> $fit_by
#> NULL
#> 
#> attr(,"class")
#> [1] "gaze_warp_spec" "list"          
```
