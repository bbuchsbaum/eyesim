# eyesim: eye-movement similarity and GazeWeave models

Tools for analyzing eye-movement fixation data with a focus on computing
fixation pattern similarity, density map generation, scanpath
comparison, and recognition memory paradigms. Implements template-based
similarity analysis of fixation density maps, the 'MultiMatch' algorithm
for scanpath comparison (Dewhurst et al. (2012)
[doi:10.3758/s13428-012-0212-2](https://doi.org/10.3758/s13428-012-0212-2)
), Earth Mover's Distance based similarity (Rubner, Tomasi and Guibas
(2000)
[doi:10.1023/A:1026543900054](https://doi.org/10.1023/A%3A1026543900054)
), latent-space transforms for density map comparison including CORAL
alignment (Sun, Feng and Saenko (2016)
[doi:10.48550/arXiv.1511.05547](https://doi.org/10.48550/arXiv.1511.05547)
), and 'GazeWeave', an experimental framework for cross-validated
encoding-to-recall gaze reinstatement by probabilistic replay and
coverage-conditioned temporal transport.
