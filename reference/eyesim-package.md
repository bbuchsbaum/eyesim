# eyesim: eye-movement similarity and GazeWeave models

Tools for analyzing eye-movement fixation data with a focus on computing
fixation pattern similarity, density map generation, scanpath
comparison, and recognition memory paradigms. Implements template-based
similarity analysis, the MultiMatch algorithm for scanpath comparison,
cross-recurrence quantification analysis (CRQA), Earth Mover's Distance
(EMD) based similarity, GazeWeave probabilistic replay and registered
coverage-conditioned temporal transport, and latent-space transforms
(PCA, CORAL, CCA) for density map comparison.
