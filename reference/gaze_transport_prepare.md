# Prepare one immutable gaze path for repeated Transport scoring

Prepare one immutable gaze path for repeated Transport scoring

## Usage

``` r
gaze_transport_prepare(path, spec)
```

## Arguments

- path:

  A fixation path or prepared gaze measure.

- spec:

  A \[gaze_transport_spec()\].

## Value

A prepared path with duration mass and local-edge terms.
