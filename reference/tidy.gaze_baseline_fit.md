# Tidy GazeWeave comparator results

Tidy GazeWeave comparator results

## Usage

``` r
# S3 method for class 'gaze_baseline_fit'
tidy(x, diagnostics = FALSE, ...)
```

## Arguments

- x:

  A \`gaze_baseline_fit\`.

- diagnostics:

  Include calibration, rank, status, and fold diagnostics.

- ...:

  Unused.

## Value

A tibble of held-out comparator results.
