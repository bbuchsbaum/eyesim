# Tidy GazeWeave Replay results

Tidy GazeWeave Replay results

## Usage

``` r
# S3 method for class 'gaze_replay_fit'
tidy(x, diagnostics = FALSE, ...)
```

## Arguments

- x:

  A \`gaze_replay_fit\`.

- diagnostics:

  Include calibration, rank, convergence, and fold columns.

- ...:

  Unused.

## Value

A tibble with identifiers and held-out \`gaze_info_bits\`.
